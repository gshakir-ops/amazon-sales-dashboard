# Data Processing & Exports

This directory contains CSV exports generated from the cleaned dataset.

## Files

- **SalesByMonth.csv** — 48 months of sales data (2019-2022)
- **SalesByCategory.csv** — Sales aggregated by product category
- **Top5Products.csv** — Top 5 products by total sales
- **Top5ProductsByYear.csv** — Top 5 products per year (2019-2022)
- **SalesByDayOfWeek.csv** — Sales pattern by day of week
- **SalesByYear.csv** — Yearly aggregates
- **SalesByPriceRange.csv** — Revenue distribution by price tier

## Generation

These files are auto-generated by:
```bash
python src/create_dashboard_data.py
```

They are used by:
1. The interactive HTML dashboard
2. Power BI visualizations
3. Further analysis as needed

Do not manually edit these files - regenerate them if the source data changes.
